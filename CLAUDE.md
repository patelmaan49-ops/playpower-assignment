# Project notes

React + TypeScript + Vite. Desktop only.

- `npm run dev` to run, `npx tsc` and `npm run build` to check.
- No code comments. One component per file in `src/components`.
- Listing content lives in `src/data.ts`.
- Overlays (photo tour, lightbox) use `useModal` from `src/hooks.ts` for focus handling.
